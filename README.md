# Nexus SaaS Dashboard

A fully responsive, multi-page SaaS application UI featuring a cinematic dark theme, interactive data visualization, and a dynamic sidebar.

## 🚀 Features
- **App-Like Layout**: Fixed sidebar, sticky top navigation, and scrollable main content area.
- **Interactive Charts**: Powered by Chart.js (Line chart for revenue, Doughnut chart for traffic).
- **Light/Dark Mode Toggle**: Saves user preference to LocalStorage.
- **User Profile Dropdown**: Functional click-outside-to-close dropdown.
- **Responsive**: Sidebar collapses on smaller screens.

## 🛠️ Tech Stack
- HTML5 / CSS3 (CSS Variables, Grid, Flexbox)
- Vanilla JavaScript
- Chart.js (CDN)
- Phosphor Icons (CDN)
